## Реализовано

HTTPS REST-клиент: OAuth/кеш/refresh, обнаружение Lite через список моделей, JSON Schema/Zod, quota/auth/TLS/timeout/refusal. Сертификаты официального источника проверяются и нормализуются OpenSSL; TLS никогда не отключается. Ключ хранится в серверном секрете, токен только в памяти.

Три действия организатора: группировки, модерация, резюме. До отправки выбираются слова и явно подтверждается исключение персональных сведений. Передаются только уникальные выбранные слова, частоты и номера групп. Названия групп, cookie/ID и исходные строки не передаются. Автофильтр очевидных персональных сведений неполон, требуется проверка организатора.

Задания/решения/usage в PostgreSQL, одно generation между процессами через advisory lock, лимиты и кеш. Внешний запрос не держит транзакцию или блокировку вопроса. После потери владельца running помечается interrupted следующим запуском. Нет повторной генерации после неоднозначного timeout/5xx. Usage и фактическая версия модели сохраняются до семантической проверки, включая отклонённые результаты.

Предложения не применяются автоматически. Проверяются существование слов, уникальность/непересечение source, каноническое слово внутри source, точные evidence counts. Генерация дополнительно ограничена enum выбранных слов и размером доступного пакета. Индивидуальные решения сохраняются; оригиналы неизменны. Резюме публикуется отдельной кнопкой, отзывается и скрывается при новых данных; revision блокирует устаревшие решения. Сессия/Origin/строгая схема защищают admin endpoints; public получает только одобренное резюме.
