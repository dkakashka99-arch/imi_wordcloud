# Доставка релиза

GitHub Actions передаёт проверенный git archive точного SHA и SHA256SUMS по SSH с закреплённым ключом хоста. VPS собирает те же production Docker targets через доступный Docker Hub. Секреты находятся вне каталога сборки, в shared, и не передаются в build. CI до деплоя проверяет типы, тесты, production-сборку и Docker.

Такой режим выбран после фактического измерения медленной передачи больших архивов образов GitHub → VPS и успешной прямой загрузки postgres:17-bookworm с VPS. Для возврата к сборке образов на runner установите repository variable DEPLOY_BUILD_ON_VPS=false. В обоих режимах сохраняются резервная копия, проверка текущего main, миграции и rollback.

Резервная копия выполняется до сборки и переключения. Во время сборки прежний контейнер продолжает работать. Контролируйте память и свободный диск; не выполняйте volume prune. Исходники releases сохраняются для проверки SHA и отката. Первоначальная сборка на VPS может длиться дольше при холодном npm-кэше.
