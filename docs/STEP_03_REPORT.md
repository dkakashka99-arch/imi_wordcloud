# Шаг 3 — модерация, экспорт, сравнение

Реализация подготовлена в feature/03-moderation-display поверх неизменённого шага 2. Шаг 2 ещё не слит: native PostgreSQL / browser gate заблокирован биллингом salakal.

## Реализовано

- Миграция 0002: stop_words / word_aliases, premoderation вопроса, rehearsal мероприятия.
- Защищённые admin GET/POST модерации с проверкой сессии, Origin, строгой схемой, лимитом тела и принадлежностью вопроса мероприятию. Серверная пагинация по 100 ответов.
- Скрытие/возврат, предмодерация новых ответов, точный нормализованный стоп-лист и ручные алиасы без цепочек/циклов. Event → question lock сериализует правила с приёмом ответов. Исходники неизменны; revision обновляет экран.
- Два защищённых CSV с BOM/кавычками/защитой формул, исходники и видимые агрегаты. Ограничение 50 000 ответов с явной ошибкой вместо усечения. Экспорт не включает cookie или ID участника.
- Отдельные репетиционные копии структуры и правил без ответов. Тестовые данные помечены is_demo и физически принадлежат другому мероприятию. Нет переключения live-опроса в demo с последующим смешиванием данных.
- Панель модерации/экспорта и режим двух групп на проекторе с независимыми QR и счётчиками; мобильная компоновка, отметки репетиции.
- Browser E2E для буквального HTML, одобрения/скрытия, CSV download, сравнения и overflow прошёл в Chromium/WebKit в новом CI.
