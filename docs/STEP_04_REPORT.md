# Этап4 — GigaChat

Ветка feature/04-gigachat-ai, PR #3 нового репозитория dkakashka99-arch/imi_wordcloud. База develop08aa19b24fc89ec3d092d7b9b728a8d1af5bf1d0. Runtime AI по умолчанию выключен; production не публикуется.

Реализованы типизированный HTTPS REST-клиент с OAuth/кешем/refresh, обнаружение Lite через список моделей, JSON Schema и Zod, обработка quota/auth/TLS/timeout/refusal. Задания и решения сохраняются PostgreSQL; generation сериализована advisory lock между процессами. Нет транзакции вопроса во время внешнего запроса. Вход — проверенные организатором уникальные слова/частоты/номера групп, ограниченный пакет, автоматическая фильтрация очевидных персональных сведений. Нет сырых ответов и cookie/ID в outbound payload.

Три действия в админке: группировки, модерация, резюме. Результаты не применяются автоматически. Проверяются существование слов, уникальность группировок, ссылки и точные evidence counts. Одобрение/отклонение сохраняется, исходные ответы неизменны; revision защищает от устаревших решений. Публикация резюме отдельной кнопкой, скрытие при новых данных, отзыв публикации. Все admin endpoints проверяют сессию/Origin/строгую схему; public получает только одобренное резюме без AI-заданий/сырья.

Локально на первой версии: lint/typecheck, 12 unit, production build; 23 integration PGlite PASS, 1 native-concurrency test пропущен только для односоединительного WASM-стенда. Public/admin HTTP PASS, включая disabled AI и запрет доступа. Новые браузерные сценарии и последние исправления ожидают CI; не считать ещё проверенными.
